# Arma Missions

Depot de missions Arma 3.

## Organisation

```text
missions/
  breaching.VR/
  hazmat.VR/
```

Chaque dossier correspond a une mission Arma 3 et peut etre copie directement dans le dossier `missions` du profil Arma.

## Missions

| Mission | Carte | Usage |
| --- | --- | --- |
| `breaching.VR` | VR | Mission de test pour `OPA_breaching` et `OPA_attachment`. |
| `hazmat.VR` | VR | Mission de test pour `OPA_chemical`. |

## Mods testes

La mission `breaching.VR` est prevue pour tester :

- `OPA_breaching`
- `OPA_attachment`

La mission `hazmat.VR` est prevue pour tester :

- `OPA_chemical`

## Utilisation

1. Copier le dossier d'une mission depuis `missions/`.
2. Le coller dans le dossier de missions du profil Arma 3.
3. Ouvrir la mission dans l'editeur Eden.
